# Слайды — простая замена PowerPoint для Android

Редактор презентаций: слайды, текст, фигуры, картинки, фон, показ на весь экран,
сохранение в файлы. Ни одной внешней зависимости, только стандартный Android API.

## Что уже есть

- Слайды 16:9, лента миниатюр внизу, добавление и удаление слайдов.
- Текст: любой размер, цвет, перенос строк, перетаскивание по слайду.
- Фигуры: прямоугольник и овал, любой цвет.
- Картинки из галереи.
- Фон слайда из палитры.
- Показ: тап по левой трети — назад, по остальному — вперёд, полноэкранный режим.
- Файлы: «Сохранить», «Сохранить как…», «Открыть…», «Новая презентация».
  Файлы лежат внутри приложения; черновик сохраняется сам при выходе.

## Чего пока нет

Списки, таблицы, анимации, экспорт в настоящий `.pptx`, изменение размера объектов
уголками (объект двигается, а размер задаётся при создании). Всё это можно добавить.

## Как собрать .apk без компьютера (через GitHub)

1. В браузере телефона зайдите на github.com и создайте пустой репозиторий
   (например `slides-app`), **без** README.
2. На странице репозитория: `Add file` → `Upload files`.
   Перетащите/выберите все файлы из папки `Download/SlideDeck`, сохранив структуру:
   папки `app`, `.github`, файлы `build.gradle`, `settings.gradle`, `gradle.properties`.
   Если браузер не даёт выбрать папки — проще загрузить через GitHub Desktop
   или залить архивом с компьютера.
3. Откройте вкладку `Actions` в репозитории, слева выберите **Build APK**,
   справа нажмите `Run workflow` → `Run workflow`.
4. Через 2–4 минуты внизу страницы сборки появится раздел **Artifacts**,
   скачайте `slides-apk.zip`, распакуйте — внутри `app-debug.apk`.
5. Откройте `app-debug.apk` на телефоне и разрешите установку из этого источника.

APK подписан отладочным ключом — для личного использования этого достаточно.

## Сборка на компьютере

Android Studio → Open → папка `SlideDeck` → Build → Build App Bundle(s)/APK(s).
Нужен JDK 17 и Android SDK 34 (Studio предложит установить сам).

## Структура

```
app/src/main/java/com/narezany/slides/
  Model.java            данные (Deck, Slide, Element) + отрисовка (Render)
  MainActivity.java     редактор: панель, холст (SlideView), миниатюры (ThumbView)
  PresentActivity.java  полноэкранный показ
app/src/main/AndroidManifest.xml
```
